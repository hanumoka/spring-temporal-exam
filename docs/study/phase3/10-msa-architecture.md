## 2. 컴포넌트별 역할 정리

| 분류 | 컴포넌트 | 포트 | 역할 |
|------|----------|------|------|
| **Temporal 인프라** | temporal-server | 21733 | Workflow 상태 관리, Task Queue 관리 |
| | temporal-postgresql | 21432 | Temporal 내부 데이터 저장 (Event History) |
| | temporal-ui | 21088 | Workflow 모니터링 웹 UI |
| **애플리케이션** | orchestrator-temporal | 21081 | Workflow 정의 + Worker 호스팅 + REST API |
| | service-order | 21082 | 주문 도메인 (CRUD) |
| | service-inventory | 21083 | 재고 도메인 (예약/확정/취소) |
| | service-payment | 21084 | 결제 도메인 (생성/승인/환불) |
| | service-notification | 21085 | 알림 서비스 (Redis Stream Consumer) |
| **공유 인프라** | mysql | 21306 | 애플리케이션 데이터 (주문/재고/결제) |
| | redis | 21379 | 캐시, 분산 락, 멱등성 키, MQ |

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                              데이터 저장 위치 정리                                       │

│                                                                                         │
│   ┌───────────────────────────────────────────────────────────────────────────────────┐ │
│   │  Temporal PostgreSQL (:21432)                                                     │ │

│                                                                                         │
│   ┌───────────────────────────────────────────────────────────────────────────────────┐ │

│   orchestrator-temporal                                                                │
│     ├── ② Workflow 시작 / Event History 저장 ──────────► Temporal PostgreSQL           │
│     └── ③ Activity 실행 / MSA 서비스 호출 ─────────────► MSA Services                 │
```

## 5. 실패 시 보상 흐름

```
┌─────────────────────────────────────────────────────────────────────────────────────────┐
│                          실패 시 보상 트랜잭션 흐름                                      │
│  시나리오: T3-2 (결제 승인)에서 실패 → 보상 실행                                       │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│   orchestrator-temporal (Worker)                    MSA Services                        │
│       │                                                                                 │
│       │  ════════════ 정방향 (Forward) ════════════                                    │
│       │                                                                                 │
│       │  T1: createOrder ──────────────────────────► service-order     ✅ 성공          │
│       │      orderId = 123                                                              │
│       │      saga.addCompensation(cancelOrder)                                         │
│       │                                                                                 │
│       │  T2: reserveStock ─────────────────────────► service-inventory ✅ 성공          │
│       │      saga.addCompensation(cancelReservation)                                   │
│       │                                                                                 │
│       │  T3-1: createPayment ──────────────────────► service-payment   ✅ 성공          │
│       │        paymentId = 456                                                          │
│       │        saga.addCompensation(refundPayment)                                     │
│       │                                                                                 │
│       │  T3-2: approvePayment ─────────────────────► service-payment   ❌ 실패!        │
│       │                                                (잔액 부족)                     │
│       │                                                                                 │
│       │  ════════════ 보상 (Compensation) ════════════                                 │
│       │                                                                                 │
│       │  catch (ActivityFailure e) {                                                   │
│       │      saga.compensate();  // 자동 역순 실행!                                    │
│       │  }                                                                              │
│       │                                                                                 │
│       │  보상 스택 (LIFO):                                                             │
│       │  ┌───────────────────────┐                                                     │
│       │  │ refundPayment         │ ← 가장 마지막 등록                                  │
│       │  │ cancelReservation     │                                                     │
│       │  │ cancelOrder           │ ← 가장 처음 등록                                    │
│       │  └───────────────────────┘                                                     │
│       │                                                                                 │
│       │  C3: refundPayment ────────────────────────► service-payment   ✅ 환불 완료    │
│       │      POST /payments/456/refund                                                 │
│       │                                                                                 │
│       │  C2: cancelReservation ────────────────────► service-inventory ✅ 재고 복구    │
│       │      POST /inventory/1/cancel                                                  │
│       │                                                                                 │
│       │  C1: cancelOrder ──────────────────────────► service-order     ✅ 주문 취소    │
│       │      PATCH /orders/123/cancel                                                  │
│       │                                                                                 │
│       │  return OrderResult.failure("잔액 부족", workflowId)                           │
│       ▼                                                                                 │
│                                                                                         │
│   최종 상태:                                                                           │
│   ┌─────────────────────────────────────────────────────────────────────────────────┐  │
│   │  orders:     id=123, status=CANCELLED                                          │  │
│   │  inventory:  productId=1, quantity=100 (원래대로 복구)                          │  │
│   │  payments:   id=456, status=REFUNDED                                           │  │
│   │  Workflow:   Completed (비즈니스 실패지만 Workflow는 정상 종료)                 │  │
│   │  결과:       {success: false, error: "잔액 부족"}                              │  │
│   └─────────────────────────────────────────────────────────────────────────────────┘  │
│                                                                                         │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
